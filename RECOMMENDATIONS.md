## ПРІОРИТЕТ 1 (КРИТИЧНО) - Реалізувати ASAP

### 1.1 Circuit Breaker паттерн

**Проблема:** Якщо синхронізація постійно не вдається (10+ разів), ESP32 продовжить намагатися кожні 30 хвилин, зливаючи батарею.

**Рішення:** Активувати "circuit breaker" - кількох невдачах зупинити спроби на 1-2 години.

**Час реалізації:** 30 хвилин

**Файл для редагування:** `src/google_sheets_sync.cpp`

**Код для додавання:**

```cpp
// У google_sheets_sync.h додати:
struct CircuitBreaker {
    uint16_t failureCount = 0;
    unsigned long lastFailureTime = 0;
    static const int THRESHOLD = 5;
    static const unsigned long COOLDOWN_MS = 3600000;  // 1 час
};

extern CircuitBreaker syncCircuitBreaker;

// У google_sheets_sync.cpp у функцію syncToGoogleSheets:
if (syncCircuitBreaker.failureCount >= 5) {
    if (millis() - syncCircuitBreaker.lastFailureTime < 3600000) {
        Serial.println("⛔ Circuit breaker активний (надто багато помилок)");
        return false;
    }
    syncCircuitBreaker.failureCount = 0;
}

// При помилці:
syncCircuitBreaker.failureCount++;
syncCircuitBreaker.lastFailureTime = millis();

// При успіху:
syncCircuitBreaker.failureCount = 0;
```

### 1.2 Детальніше логування помилок

**Проблема:** При помилці виводить тільки "❌ Помилка відправки", складно діагностувати причину.

**Рішення:** Додати errno, heap, RSSI, timeout інформацію.

**Час реалізації:** 20 хвилин

**Місце для додавання:** `src/google_sheets_sync.cpp`, функція `sendBatchToSheets`

**Приклади замін:**

```cpp
// ЗАМІСТЬ:
if (!client->connect("script.google.com", 443)) {
    Serial.printf("❌ Підключення не вдалось (heap: %u)\n", ESP.getFreeHeap());
    delete client;
    return false;
}

// ЗАМІСТЬ:
Serial.printf("❌ Connect failed: heap=%u RSSI=%d errno=%d\n",
             ESP.getFreeHeap(), WiFi.RSSI(), errno);
Serial.printf("   Max allocable block: %u bytes\n", ESP.getMaxAllocHeap());
delete client;
return false;
```

### 1.3 Моніторинг якості WiFi

**Проблема:** Не видно якості WiFi сигналу, складно діагностувати "вечірні" виходи синхронізації.

**Рішення:** Логувати RSSI (сила сигналу), channel, packet loss.

**Час реалізації:** 15 хвилин

**Функція для додавання:**

```cpp
// У google_sheets_sync.cpp додати перед sendBatchToSheets:
Serial.printf("📶 WiFi Diagnostics:\n");
Serial.printf("   Signal: %d dBm\n", WiFi.RSSI());
Serial.printf("   Channel: %d\n", WiFi.channel());
Serial.printf("   Status: %d\n", WiFi.status());

int signalQuality;
int rssi = WiFi.RSSI();
if (rssi >= -50) signalQuality = 100;
else if (rssi >= -70) signalQuality = 80;
else if (rssi >= -80) signalQuality = 60;
else signalQuality = 40;

Serial.printf("   Estimated quality: %d%%\n", signalQuality);
```

## ПРІОРИТЕТ 2 (ВАЖЛИВО) - Додати через тиждень

### 2.1 Локальне кешування невідправлених даних

**Проблема:** При довгому відключенні WiFi дані у RAM втрачаються.

**Рішення:** Зберігати невідправлені батчі у SPIFFS, відправляти при з'єднанні.

**Час реалізації:** 1.5 години

**Файл:** Новий `src/sync_cache.cpp` + `src/sync_cache.h`

**Основна ідея:**

```cpp
// Якщо синхронізація не вдалася - кешуємо
if (!sendBatchToSheets(batch, count)) {
    cacheFailedBatch(batch, count);
}

// При наступному успішному з'єднанні:
void autoSyncTask() {
    // ... існуючий код ...

    if (success) {
        // Тепер спробуємо відправити кешовані
        resendCachedBatches();
    }
}
```

**Переваги:**
- Не втрачаємо дані при краху
- Автоматично синхронізуємо затримані дані

### 2.2 Компресія CSV для великих батчів

**Проблема:** CSV може сягати 5-10 KB, потребує багато пам'яті при SSL.

**Рішення:** Гніздити дані партіями по 15-20 записів замість 30.

**Час реалізації:** 30 хвилин (тільки config зміни)

**Зміни у `src/config.h`:**

```cpp
#define SYNC_BATCH_SIZE 20  // Замість 50, легше на пам'ять
#define SYNC_BATCH_COUNT 2  // Завжди надсилати partitions
```

### 2.3 Jitter для автосинхронізації

**Проблема:** Якщо у вас декілька ESP32 - всі синхронізуються одночасно.

**Рішення:** Додати випадкову затримку (±5 хвилин) до інтервалу.

**Час реалізації:** 10 хвилин

**Місце для додавання:** `src/google_sheets_sync.cpp`, функція `autoSyncTask`

```cpp
// ЗАМІСТЬ:
if (now - lastCheckTime < 60000) return;

// ЗАМІСТЬ:
unsigned long checkInterval = 60000 + random(0, 300000);  // ±5 хвилин
if (now - lastCheckTime < checkInterval) return;
```

## ПРІОРИТЕТ 3 (NICE-TO-HAVE) - За чекером енергії

### 3.1 Динамічне батчування залежно від пам'яті

**Ідея:** Якщо heap < 15 KB - надсилаємо партії по 10 записів, не 30.

**Час реалізації:** 45 хвилин

**Функція:**

```cpp
uint16_t getOptimalBatchSize() {
    uint32_t freeHeap = ESP.getFreeHeap();

    if (freeHeap > 20000) return 30;  // Нормально
    if (freeHeap > 15000) return 20;  // Натяг
    if (freeHeap > 10000) return 10;  // Критично

    return 5;  // Дуже критично
}
```

## Глосарій термінів

- **Circuit Breaker** - паттерн, що блокує операції після N невдач
- **Jitter** - додавання випадкової затримки до синхронізованих дій
- **Batch** - група записів, надіслані разом (економія запитів)
- **RSSI** - Received Signal Strength Indicator (сила WiFi сигналу)
- **Heap** - динамічна пам'ять для розподілу під час роботи
