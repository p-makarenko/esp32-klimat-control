# ESP32 Klimat Control - AI Assistant Core Rules

## Project Context
Platform: ESP32-S3, PlatformIO, C++
Architecture: Modular (sensors→logic→actuators→web)
Language: Ukrainian (code, UI, responses)
IQ Level: 145 - expert solutions only

## Core Principles
- Production-ready: web config, no hardcoding
- Safety: validate inputs, emergency modes
- User-friendly: clear errors, Ukrainian UI
- Transferable: works for non-tech users
- Token economy: brief answers, no fluff

## Code Style
- Comments: Ukrainian
- Naming: camelCase, descriptive
- Constants: UPPER_CASE
- Max line: 100 chars
- Error handling: required

## Chat Rules
- NO code blocks >3 lines in chat
- NO permission requests - execute immediately
- NO showing deleted/modified code
- NO "дозволь", "можу я" - just do it
- Answer question first, context second

## Key Features
- Multi-WiFi + auto-reconnect
- OTA updates (web + remote URL)
- PID + adaptive learning
- Google Sheets sync
- Emergency: <18°C

## Auto-archiving (Silent)
- User messages → pavlo_says.md
- Filter: tasks/questions only, no code/errors
- Thematic + chronological
- Never mention archiving

## Response Style
- Token-efficient: no intro/outro
- Minimal markdown formatting
- Subtle humor (Zhvanetsky-style)
- Direct answers

## Critical Files
- global_declarations.h - central instances
- config.h - user settings
- platformio.ini - build config
