# Міграція зі старої інструкції

## Що змінилось

### ❌ Було (одним файлом):
```
.clinerules: ~3000 токенів
Всі інструкції разом
Читається при кожному запиті
90,000 токенів/день при 30 запитах
```

### ✅ Стало (модульна система):
```
.clinerules: ~400 токенів (core)
+ docs/.ai-instructions/*.md (за потреби)
Економія: 80% токенів
~18,000 токенів/день при 30 запитах
```

## Покрокова міграція

### Крок 1: Backup старої інструкції
```bash
cp .clinerules .clinerules.backup
```

### Крок 2: Створити нову структуру
```bash
# Скопіювати з klimat-ai-rules/
cp klimat-ai-rules/.clinerules ./
cp -r klimat-ai-rules/docs ./
```

### Крок 3: Перевірити роботу
Зробіть кілька тестових запитів:
- Простий: "Виправ typo"
- Середній: "Додай валідацію"
- Складний: "Реалізуй OTA"

### Крок 4: Налаштувати під ваш проект
Відредагуйте `.clinerules`:
- Змініть назву проекту
- Оновіть список критичних файлів
- Додайте специфічні для вашого проекту правила

## Що видалено (навмисно)

### Дублювання
Старий файл мав багато повторень:
- "не показуй код >3 рядків" було у 3 місцях
- Приклади коду дублювались
- Загальні правила повторювались

Тепер кожне правило в одному місці.

### Надмірна деталізація
Деякі секції були занадто детальні:
- Довгі приклади коду → скорочено
- Повторювані пояснення → об'єднано
- Теоретичні розмірковування → видалено

Тепер фокус на практичному застосуванні.

## Порівняння ефективності

### Тест на 10 типових запитах:

**Стара система:**
```
10 запитів × 3000 токенів = 30,000 токенів
```

**Нова система:**
```
5 простих × 400 = 2,000
3 середні × 1000 = 3,000
2 складні × 1500 = 3,000
Всього: 8,000 токенів
```

**Економія: 22,000 токенів (73%)**

## Troubleshooting

### Claude не знаходить файли?
Перевірте шляхи:
```bash
ls -la .clinerules
ls -la docs/.ai-instructions/
```

### Claude читає всі файли кожного разу?
Ні, Claude розумний - читає тільки релевантні.
Але ви можете перевірити токени в кожній відповіді.

### Щось працює не так?
Поверніться до backup:
```bash
cp .clinerules.backup .clinerules
```

## Подальша оптимізація

### Якщо токенів все ще багато:

1. **Скоротіть .clinerules ще більше**
   - Залиште тільки абсолютно критичне
   - Винесіть навіть "Key Features" в окремий файл

2. **Об'єднайте рідко використовувані файли**
   - Якщо skeptical-architect рідко потрібен → додайте в production-ready

3. **Використовуйте більше скорочень**
   - Англійська де можливо
   - Списки замість параграфів
   - Видаліть зайві слова
