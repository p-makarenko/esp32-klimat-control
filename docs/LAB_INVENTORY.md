# Інвентаризація лабораторії (AliExpress Hardware Catalog)

Цей документ містить повний структурований перелік електронних компонентів, датчиків, силових модулів, освітлення, блоків живлення та інструментів лабораторії (зібрано автоматично з історії замовлень AliExpress станом на листопад 2026 р.).

Файл слугує постійним довідником для розробки проєкту **Klimat Kontrol**, щоб не описувати наявне залізо вручну.

  - Шлейфи **JST XH2.54 8-pin 20 см** (5 шт., 11.03.2026).
  - Комплект пінів та корпусів **Dupont 2.54 мм Male-Female** (200 шт., 22.12.2025).
  - Роз'єми **Micro-USB 5-pin** на плату (10 шт., 19.11.2025).

- **Паяльне, ЧПУ та спецобладнання:**
  
  - Гравірувальні твердосплавні V-фрези **3.175 мм для друкованих плат (PCB)** (`HUHAO 5944/5945` 2025 р. та набори 2018 р.), кінцеві фрези по алюмінію/акрилу/дереву, свердла HSS (99 шт.) та Форстнера.
