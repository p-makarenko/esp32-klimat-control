# Енергоконтролер - Налаштування та Використання

## 📋 Короткий опис

Новий модуль `energy_monitor` дозволяє монitorити споживання енергії за допомогою лічильника **PZEM004Tv30**.

Модуль адаптований на основі `indacator2.txt` і включає:
- **Веб-інтерфейс** для перегляду даних (http://ip/energy)
- **REST API** для отримання поточних вимірювань
- **Історія енергії** у форматі CSV (LittleFS)
- **Статистика** споживання (день, місяць)

## 🔧 Активація модуля

### Варіант 1: Через `platformio.ini`

```ini
[env:esp32dev]
build_flags =
    -DENABLE_ENERGY_MONITOR=1
```

### Варіант 2: Через `config.h`

```cpp
#define ENABLE_ENERGY_MONITOR 1
```

## 🔌 Підключення апаратури

**PZEM004Tv30** → **ESP32**

| PZEM | ESP32 |
|------|-------|
| RX   | GPIO16 (PZEM_RX_PIN) |
| TX   | GPIO17 (PZEM_TX_PIN) |
| GND  | GND   |
| VCC  | 5V    |

> Якщо потрібні інші піни, змініть константи у `energy_monitor.cpp`:
> ```cpp
> #define PZEM_RX_PIN 16
> #define PZEM_TX_PIN 17
> ```

## 🌐 Веб-API

### GET /energy
Повна сторінка моніторингу з графіком

**Приклад:**
```
http://192.168.1.100/energy
```

### GET /energy/api
JSON з поточними вимірюваннями

**Відповідь:**
```json
{
  "v": 230.5,        // Напруга (V)
  "c": 2.15,         // Струм (A)
  "p": 495.0,        // Потужність (W)
  "e": 42.56,        // Енергія (kWh)
  "f": 50.0,         // Частота (Hz)
  "pf": 0.98,        // Коефіцієнт потужності
  "err": false       // Помилка читання
}
```

### GET /energy/history
CSV файл з історією енергії

**Формат:**
```csv
timestamp,energy
1705000000,42.50
1705003600,42.65
1705007200,42.80
```

### GET /energy/stats
Статистика енергоспоживання

**Відповідь:**
```json
{
  "totalEnergy": 1025.5,
  "recordCount": 168,
  "avgDaily": 6.04
}
```

## 🎨 Інтерфейс

Веб-інтерфейс (`/energy`) включає:

1. **Карточки з метриками**
   - Напруга (V)
   - Струм (A)
   - Потужність (W)
   - Енергія (kWh)

2. **Графік з режимами**
   - **LIVE** - реальний час (потужність кожні 2 сек)
   - **ДЕНЬ** - споживання за день
   - **МІСЯЦЬ** - споживання за місяць

3. **Статус з'єднання**
   - 🟢 ONLINE (зелений)
   - 🔴 OFFLINE / ERROR (червоний)

## 📊 Файлова система

Дані зберігаються у LittleFS:

```
/energy_history.csv   - Історія енергії (CSV формат)
```

Кожний час система записує поточне значення `energy` у CSV.

## ⚙️ Налаштування

### Інтервал оновлення даних

За замовчуванням - **2 секунди**

Змініть у `energy_monitor.cpp`:
```cpp
if (now - lastEnergyUpdate < 2000) {  // 2000 мс = 2 сек
    return;
}
```

### Інтервал запису історії

За замовчуванням - **1 раз на годину** (при зміні часу)

Логіка у `updateEnergyData()`:
```cpp
if (currentEnergyHour != timeinfo.tm_hour) {
    appendEnergyHistory(energyData.energy);
    currentEnergyHour = timeinfo.tm_hour;
}
```

## ❌ Вирішення проблем

| Проблема | Рішення |
|----------|---------|
| "Енергоконтролер вимкнено" | Встановіть `ENABLE_ENERGY_MONITOR=1` |
| Помилка читання PZEM | Перевірте з'єднання RX/TX та живлення |
| Пуста історія | Перезавантажте пристрій для запису за годину |
| "Файл не знайдено" | LittleFS не ініціалізована, перевірте `/energy_history.csv` |
