# 🏠 ESP32 Клімат Контроль

[![PlatformIO](https://img.shields.io/badge/PlatformIO-ESP32--S3-orange.svg)](https://platformio.org/)
[![Arduino](https://img.shields.io/badge/Framework-Arduino-blue.svg)](https://www.arduino.cc/)
[![License](https://img.shields.io/badge/License-MIT-green.svg)](LICENSE)

Інтелектуальна система управління мікрокліматом на базі ESP32-S3 з веб-інтерфейсом та автоматичною адаптацією.

## 📊 Статистика проєкту

- **📝 Рядків коду:** ~6,373 рядки (C/C++)
- **💾 Розмір прошивки:** ~1,040 KB
- **🔧 Токенів використано:** ~65,000+ за сесію розробки
- **📅 Початок розробки:** 7 грудня 2025
- **⏱️ Активна розробка:** 28+ днів
- **📦 Версія:** v4.5 (автоінкремент)

## ✨ Основні можливості

### 🌡️ Моніторинг
- **BME280** - температура, вологість, тиск повітря
- **2x DS18B20** - температура води (вхід/вихід)
- Розрахунок точки роси та теплової ефективності
- Система збору та аналізу статистики

### 🎛️ Управління обладнанням
- **PWM контроль:**
  - Насос зволожувача (0-100%)
  - Вентилятор (0-100%)
  - Витяжка (0-100%)
- **Сервопривід** - заслінка вентиляції (0-180°)
- **Механічний перемикач** - аварійне відключення

### 🤖 Інтелектуальні режими
- **AUTO** - автоматична підтримка параметрів
- **MANUAL** - ручне керування через веб
- **FORCE** - форсований режим (< 20°C)
- **EMERGENCY** - аварійний режим (< 18°C)
- **PID регулятор** - точне підтримання температури
- **Адаптивне навчання** - система запам'ятовує ефективні режими

### 🌐 Мережеві можливості
- **WiFi підключення** з автоперепідключенням
- **Веб-інтерфейс** - повне управління через браузер
- **mDNS** - доступ через http://klimat.local (Mac/iOS/Linux)
- **NetBIOS** - доступ через http://klimat (Windows) - швидше за IP!
- **Багато WiFi мереж** - автовибір найсильнішого сигналу
- **NTP синхронізація** - точний час
- **OTA оновлення** - прошивка через WiFi

### 📱 Веб-інтерфейс
- Адаптивний дизайн (мобільні/планшети/ПК)
- Реал-тайм дані з оновленням кожні 30 секунд
- Графіки та історія параметрів
- Налаштування всіх параметрів
- Таймери та розклади
- Статистика та аналітика
- 🇺🇦 Підтримка України вбудована!

## 🔧 Технічні характеристики

### Обладнання
- **Плата:** ESP32-S3-DevKitC-1
- **Частота:** 240 MHz
- **RAM:** 320 KB
- **Flash:** 8 MB
- **GPIO:** 18 використовуваних пінів

### Датчики і виконавчі пристрої
- **BME280** (I2C: SDA=18, SCL=19)
- **DS18B20 x2** (OneWire: 5)
- **Servo** (PWM: 8)
- **Pump** (PWM: 16)
- **Fan** (PWM: 21)
- **Extractor** (PWM: 20)
- **Switch** (Digital: 4)

### Параметри
- **Температура:** 18-28°C (налаштовується)
- **Вологість:** 40-80% (налаштовується)
- **PWM частота:** 5000 Hz
- **PID регулятор:** Kp=2.0, Ki=0.1, Kd=0.5

## 🚀 Швидкий старт

### 1️⃣ Підключення

**Найпростіші способи (без IP):**
- Windows: http://klimat (NetBIOS - найшвидший!)
- Mac/iOS/Linux: http://klimat.local (mDNS)
- Android: IP адреса (дивись Serial Monitor)

**Резервний спосіб:**
- Дивись IP адресу в Serial Monitor
- Відкрий http://192.168.x.x

### 2️⃣ Налаштування WiFi

При першому запуску:
1. ESP32 створює точку доступу "ESP32-Klimat"
2. Підключись до неї (пароль: `12345678`)
3. Відкрий http://192.168.4.1
4. Введи дані своєї WiFi мережі

### 3️⃣ Перше використання

1. Відкрий веб-інтерфейс
2. Перевір показники датчиків
3. Обери режим (AUTO рекомендовано)
4. Встанови бажані параметри
5. Система автоматично підтримуватиме клімат

## 💻 Розробка

### Встановлення

```bash
# Клонувати репозиторій
git clone https://github.com/p-makarenko/esp32-klimat-control.git
cd esp32-klimat-control

# Встановити залежності (PlatformIO автоматично)
pio run

# Завантажити на плату
pio run --target upload

# Монітор послідовного порту
pio device monitor
```

## 🎯 Serial Commands

Команди для швидкого управління через Serial Monitor (115200 baud):

### Управління обладнанням
```
a50      # Насос 50%
b80      # Вентилятор 80%
c30      # Витяжка 30%
```

### Налаштування
```
tmin 22  # Мінімальна температура 22°C
tmax 25  # Максимальна температура 25°C
hmin 60  # Мінімальна вологість 60%
hmax 70  # Максимальна вологість 70%
```

### Таймери
```
ton 30   # Увімкнути на 30 хвилин
toff     # Вимкнути таймер
tcycle 5:0 25:0  # Цикл: 5 хв вкл, 25 хв викл
```

### Сервіс
```
s        # Статус системи
m        # Повне меню
web      # Інформація про веб-доступ
reboot   # Перезавантаження
```
