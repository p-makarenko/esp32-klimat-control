# Google Apps Script для прийому даних ESP32

## Інструкція по налаштуванню

### 1. Створення Google Таблиці

1. Відкрийте [Google Sheets](https://sheets.google.com)
2. Створіть нову таблицю
3. Назвіть її, наприклад: "ESP32 Klimat Data"

### 2. Налаштування першого рядка (заголовки)

**ВАЖЛИВО:** Перший рядок створіть вручну з наступними заголовками:

| A | B | C | D | E | F | G | H | I |
|---|---|---|---|---|---|---|---|---|
| Дата і час | Теплоносій °C | Кімната °C | BME280 °C | Вологість % | Насос % | Вентилятор % | Витяжка % | Режим |

Або можна використовувати англійські назви:

| A | B | C | D | E | F | G | H | I |
|---|---|---|---|---|---|---|---|---|
| Timestamp | Carrier Temp | Room Temp | BME Temp | Humidity | Pump | Fan | Extractor | Mode |

**Примітка:** ESP32 НЕ відправляє заголовки, тільки дані!

### 3. Створення Google Apps Script

1. В вашій таблиці натисніть **Розширення** > **Apps Script**
2. Видаліть весь код, який там є
3. Вставте код нижче:

```javascript
function doPost(e) {
  try {
    var csvData = e.postData.contents;
    var sheet = SpreadsheetApp.getActiveSpreadsheet().getActiveSheet();
    var lines = csvData.split('\n');
    var count = 0;

    for (var i = 0; i < lines.length; i++) {
      if (lines[i].length > 0) {
        var values = lines[i].split(',');
        if (values.length == 9) {
          sheet.appendRow(values);
          count++;
        }
      }
    }

    return ContentService.createTextOutput('OK');
  } catch (err) {
    return ContentService.createTextOutput('ERROR');
  }
}

function testDoPost() {
  var testData = '2026-01-09 16:30:00,50.5,22.3,21.8,58.2,0,29,0,0\n2026-01-09 16:31:00,51.2,22.5,21.9,58.5,0,29,0,0';

  var e = {
    postData: {
      contents: testData
    }
  };

  var result = doPost(e);
  Logger.log(result.getContent());
}
```

### 4. Публікація Web App

1. Натисніть **Зберегти** (значок дискети)
2. Натисніть **Deploy** (Розгорнути) > **New deployment** (Нове розгортання)
3. Натисніть на іконку **шестерінки** біля "Select type"
4. Оберіть **Web app**
5. Налаштування:
   - **Description:** "ESP32 Data Receiver" (опис)
   - **Execute as:** Me (виконувати як: я)
   - **Who has access:** Anyone (доступ: будь-хто)
6. Натисніть **Deploy** (Розгорнути)
7. **Дуже важливо:** Скопіюйте **URL веб-додатку**
   - Він виглядає так: `https://script.google.com/macros/s/AKfycbz.../exec`

### 5. Налаштування ESP32

1. Відкрийте файл `src/google_sheets_sync.h` у вашому проекті
2. Знайдіть рядок:
   ```cpp
   #define GOOGLE_SCRIPT_URL "https://script.google.com/macros/s/YOUR_DEPLOYMENT_ID/exec"
   ```
3. Замініть `YOUR_DEPLOYMENT_ID` на ваш реальний URL
4. Збережіть файл
5. Скомпілюйте і завантажте прошивку на ESP32

### 6. Тестування

#### Тест 1: Перевірка Apps Script
1. В Apps Script натисніть **Виконати** > **testDoPost**
2. При першому запуску дозвольте доступ до таблиці
3. Перевірте чи з'явились 2 тестові рядки в таблиці

#### Тест 2: Ручна синхронізація з ESP32
1. Відкрийте Serial Monitor або веб-інтерфейс ESP32
2. Виконайте команду: `sheets-sync`
3. Перевірте Serial Monitor на предмет помилок
4. Перевірте чи з'явились дані в Google Таблиці

#### Тест 3: Автоматична синхронізація
1. Зачекайте 30 хвилин (або перезавантажте ESP32)
2. Система автоматично відправить дані
3. Перевірте таблицю

## Структура даних

### Формат CSV (відправляє ESP32):
```csv
1767875458,63.4,28.1,24.3,67.1,0,9,0,0
1767875518,63.9,27.2,24.3,68.1,0,9,0,0
```

### Формат в Google Sheets (після обробки):
| Дата і час | Теплоносій °C | Кімната °C | BME280 °C | Вологість % | Насос % | Вентилятор % | Витяжка % | Режим |
|------------|---------------|------------|-----------|-------------|---------|--------------|-----------|-------|
| 2026-01-08 15:30:58 | 63.4 | 28.1 | 24.3 | 67.1 | 0 | 9 | 0 | 0 |
| 2026-01-08 15:31:58 | 63.9 | 27.2 | 24.3 | 68.1 | 0 | 9 | 0 | 0 |

### Пояснення полів:
- **Дата і час**: Unix timestamp конвертується в нормальну дату
- **Теплоносій °C**: Температура теплоносія
- **Кімната °C**: Температура в кімнаті
- **BME280 °C**: Температура з датчика BME280
- **Вологість %**: Відносна вологість
- **Насос %**: Потужність насоса (0-100%)
- **Вентилятор %**: Швидкість вентилятора (0-100%)
- **Витяжка %**: Швидкість витяжки (0-100%)
- **Режим**: 0=AUTO, 1=MANUAL, 2=FORCE, 3=EMERGENCY

## Налаштування синхронізації

У файлі `google_sheets_sync.h` можна змінити:

```cpp
#define SYNC_INTERVAL_MS 1800000          // 30 хвилин (в мс)
#define SYNC_MIN_NEW_RECORDS 10           // Мінімум нових записів
#define SYNC_DAILY_HOUR 23                // Година (0-23)
#define SYNC_DAILY_MINUTE 59              // Хвилина (0-59)
#define SYNC_BATCH_SIZE 50                // Розмір пакету
```

## Команди в Serial Monitor / Веб-інтерфейсі

- `sheets-sync` - Ручна синхронізація зараз
- `sheets-stats` - Показати статистику синхронізації

## Усунення проблем

### Помилка 403 (Forbidden)
- Перевірте що в налаштуваннях Deploy вибрано "Who has access: Anyone"
- Спробуйте створити новий Deployment

### Помилка 302 (Redirect)
- Це нормально, скрипт працює
- Перевірте таблицю - дані мають з'явитись

### Помилка timeout
- Збільшіть SYNC_BATCH_SIZE до 30-40 записів
- Перевірте інтернет з'єднання ESP32

### Дані не з'являються
- Перевірте URL в `GOOGLE_SCRIPT_URL`
- Запустіть `testDoPost()` в Apps Script
- Перевірте Serial Monitor на предмет помилок

## Безпека

- Дані передаються через HTTPS
- URL публічний, але таблиця приватна
- Ніхто крім вас не має доступу до таблиці
- Можна додати перевірку API ключа для додаткової безпеки
