```

```

**З телефону Android:**

**З телефону iOS:**
```
http://klimat.local
```

## Доступ до пристрою в різних мережах

Система підтримує два способи забезпечення постійної адреси доступу:

### 1. mDNS (рекомендовано) ⭐

**mDNS дозволяє звертатися до пристрою за іменем замість IP-адреси.**

**Адреса доступу:** `http://klimat.local`

#### Переваги:
- ✅ Працює в будь-якій мережі автоматично
- ✅ Не потрібно запам'ятовувати IP-адресу
- ✅ Не вимагає налаштування
- ✅ Працює відразу після підключення

#### Підтримка пристроїв:
- **Windows:** підтримується (через Bonjour або iTunes)
- **macOS/iOS:** вбудована підтримка
- **Linux:** встановіть avahi-daemon
- **Android:** потрібен додатковий додаток (наприклад, BonjourBrowser)

#### Якщо не працює на Windows:
1. Встановіть [Bonjour Print Services](https://support.apple.com/kb/DL999)
2. Або встановіть iTunes (містить Bonjour)
3. Перезавантажте комп'ютер

---

### 2. Статична IP-адреса

**Фіксована IP-адреса в межах вашої локальної мережі.**

#### Як налаштувати:

1. Підключіться до веб-інтерфейсу:
   - Через mDNS: `http://klimat.local`
   - Або через IP: `http://[поточна IP]`

2. Перейдіть на сторінку **"WiFi налаштування"**

3. Введіть параметри вашої мережі:
   - **IP адреса:** Вільна адреса з діапазону вашого роутера (наприклад, `192.168.1.100`)
   - **Шлюз (Gateway):** Адреса вашого роутера (зазвичай `192.168.1.1` або `192.168.0.1`)
   - **Маска підмережі:** Зазвичай `255.255.255.0`
   - **DNS сервер:** `8.8.8.8` (Google DNS) або DNS вашого провайдера

4. Встановіть галочку **"Використовувати статичну IP"**

5. Натисніть **"Зберегти налаштування"**

6. **Перезавантажте пристрій** для застосування змін

#### Переваги:
- ✅ Завжди однакова IP-адреса в вашій домашній мережі
- ✅ Не залежить від платформи
- ✅ Працює на всіх пристроях

#### Недоліки:
- ⚠️ Потрібно налаштовувати окремо для кожної мережі
- ⚠️ При переході в іншу мережу може не працювати

#### Як дізнатися параметри своєї мережі:

**Windows:**
```cmd
ipconfig
```
Шукайте: `Default Gateway` (це адреса шлюзу)

**macOS/Linux:**
```bash
ip route | grep default
```

## Рекомендації

### Вдома (одна мережа):
Використовуйте **mDNS** для простоти або **статичну IP** якщо потрібна максимальна надійність.

### Декілька мереж (дім, офіс, дача):
Використовуйте **mDNS** - працює скрізь без додаткового налаштування.

### Для досвідчених користувачів:
Можна комбінувати обидва методи:
- mDNS для зручності (`http://klimat.local`)
- Статична IP як резервний варіант

## Поточна інформація про мережу

Переглянути поточні налаштування можна:
1. Через веб-інтерфейс: **WiFi налаштування**
2. Через Serial Monitor при завантаженні ESP32
3. На головній сторінці веб-інтерфейсу

## Усунення проблем

### mDNS не працює:
- Перевірте, чи пристрій підключений до WiFi
- Переконайтеся, що Bonjour встановлений (Windows)
- Спробуйте перезавантажити роутер
- Деякі корпоративні мережі блокують mDNS

### Статична IP не працює:
- Перевірте, чи IP-адреса не зайнята іншим пристроєм
- Переконайтеся, що IP знаходиться в діапазоні вашої мережі
- Перевірте правильність адреси шлюзу
- Перезавантажте ESP32 після збереження налаштувань

### Не можу підключитися взагалі:
- Перевірте Serial Monitor - там показується поточна IP
- Спробуйте скинути налаштування (утримуйте кнопку BOOT при включенні)
- Якщо ESP32 створив точку доступу, підключіться до неї:
  - SSID: `ClimateControl`
  - Пароль: `12345678`
  - IP: `http://192.168.4.1`

## Автоматична зміна мережі

Система автоматично:
- Сканує доступні WiFi мережі
- Підключається до найкращої з відомих мереж
- Застосовує статичну IP якщо налаштовано
- Ініціалізує mDNS після підключення

При переході в іншу мережу ESP32 автоматично підключиться, якщо ця мережа є в списку збережених.
